# Handwritten Digit Recognition

My first Artificial Intelligence project: a handwritten digit recognition system (0–9) built using Machine Learning and an Artificial Neural Network (MLP).

### Technologies
- Python
- Scikit-learn (MLPClassifier)
- MNIST Dataset
- NumPy
- Pillow
- Tkinter
- Matplotlib & Seaborn
- Joblib

### Features
- Draw digits using the mouse
- Recognize handwritten digits
- Train and evaluate the ML model
- Display accuracy and a confusion matrix
- Save and load the trained model

**Goal:** Gain practical experience with Machine Learning fundamentals and build my first AI-powered application.
